# Secure Cloud Based Question-Paper Management System

## Run locally
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

Demo accounts:
- admin / admin123
- setter / setter123
- examiner / examiner123

## Azure deployment
Set these App Service application settings:
- SECRET_KEY = a long random value
- FERNET_KEY = generated by running:
  `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
- AZURE_STORAGE_CONNECTION_STRING = your Azure Storage connection string
- AZURE_CONTAINER = question-papers

Startup command:
`gunicorn --bind=0.0.0.0:8000 app:app`

This is a college-project MVP. For production, use managed identity/Key Vault, a production database, HTTPS-only cookies, and stricter file validation.
